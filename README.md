# Trocken-Quest

Eine kleine Familien-Web-App: Ein Kind sammelt mit trockenen Nächten, Trink-Quests und Beckenboden-Training Punkte, baut eine Block-Insel aus und kämpft gegen einen wöchentlichen Boss.

- Läuft im Browser und als App auf dem Home-Bildschirm (iPhone: Safari → Teilen → «Zum Home-Bildschirm»).
- Gemeinsamer Speicher über Supabase (Region Frankfurt). Im Code stehen nur die Projekt-Adresse und der öffentliche Schlüssel; die Zugriffsregeln liegen in der Datenbank.
- In der Datenbank steht nur ein Heldenname, kein echter Name.

Die Seite ist eine einzige Datei (`index.html`), erzeugt aus den Quelltexten im privaten Projekt.
